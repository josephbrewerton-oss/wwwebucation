# 1. Architectural Superiority Manifesto & Tri-System Independence
# -----------------------------------------------------------------------------
# Unlike traditional monolithic web applications (Next.js, React, Nuxt, Docusaurus)
# that suffer from 2–5 MB JavaScript bundles, complex hydration mismatches, CPU-heavy
# virtual DOM diffing, and video streaming bills, this platform operates on three
# strictly standalone, zero-bloat systems unified by an asynchronous event bus:
#
# SYSTEM 1: THE PORTAL SITE SPA (Native Web Standards & Web Components)
# - Framework: Zero React, Zero Virtual DOM, Zero Server-Side Hydration lag.
# - UI Architecture: Custom Web Components (<app-shell>, <native-bsl-interpreter>)
#   with in-memory micro-routing inside #ast-persistent-viewport via #page-outlet.
# - Stability: html { scrollbar-gutter: stable; } prevents Cumulative Layout Shift (CLS).
# - Offline Guarantee: 100% operational offline via ServiceWorker cache & IndexedDB.
# - Zero-Forced-Reflow: Geometric queries deferred to requestAnimationFrame; initial boot
#   skips window.scrollTo (already at 0,0); lazy chunks excluded from head modulepreload.
#
# SYSTEM 2: THE AST VECTOR PLAYER & FANTASY ENGINE (/static/player/)
# - Autonomy: Completely decoupled runtime (< 35 KB gzipped, < 150 KB uncompressed)
#   with zero external dependencies. Can run standalone, in an iframe, or in offline ZIP.
# - Fixed WASM Linear Memory: Strictly operates in a 7-page (448 KB) WASM linear memory
#   pool with zero dynamic heap allocations (no GC spikes) during 60 FPS physics loops.
# - 70x Lighter Than PhET: Boots in < 15 ms with < 8 MB RAM footprint (vs PhET's 2–5 MB
#   bundle, 1,200–2,500 ms boot time, and 45–90 MB RAM usage).
# - Tri-Mode Execution: Supports :Sim (continuous 60 FPS kinematics), :Slide (discrete
#   exploratory decks), and :Film (linear narrative choreography with time curves).
# - Negative-Space Compound Vectorization: Employs fill-rule="evenodd" compound paths
#   to carve mechanical apertures and voids into single DOM nodes with zero overdraw,
#   driven by single-cycle FMA 6-float affine matrix buffers (< 0.1 ms frame execution).
# - Smartboard Whiteboard Ink: Native in-stage quadratic Bézier vector annotation layer.
#
# SYSTEM 3: THE SOVEREIGN "IN-VISION" BSL / MAKATON VECTOR AVATAR
# - Zero-Video Architecture: Pure procedural SVG skeletal avatar running at 60 FPS
#   (< 15 KB uncompressed code, 0 KB external video feeds, £0 streaming bandwidth bills).
# - BSL Level 6 Linguistic Syntax Engine: 10-point 3D spatial register grid, directional
#   agreement verbs, polycomponential classifier predicates (CL:V, CL:B, CL:C, handling),
#   aspectual modulators (durative, intensive, habitual), and adverbial mouth morphemes.
# - Sovereign Uncoupling: Docks into the player/shell OR undocks into a separate desktop
#   window via the W3C Document Picture-in-Picture API (documentPictureInPicture).
#
# HARMONIOUS DECOUPLED DATA TIER (.ast & .astb)
# - Declarative Single Source of Truth: All 60+ simulations, lessons, and lexicons are
#   authored as human-readable S-Expressions (.ast) and companion SVGs (.svg).
# - Pre-Compiled Binary Bytecode (.astb / .astbs): Compiled with ASTB magic header,
#   string table, and opcodes for sub-0.2 ms zero-copy binary deserialization.
# - Cryptographic Integrity: Validated against signed cartridge-checksums.json.
# - Inter-System Bus: The site, player, and BSL avatar communicate exclusively via
#   asynchronous postMessage events (SUBTITLE_UPDATE, SPEECH_BOUNDARY, TOGGLE_BSL)

# 3. On-Device Agent Capabilities & In-Browser Tools (W3C WebMCP)
# -----------------------------------------------------------------------------
# Agents operating inside the client browser may invoke registered tools via:
# window.modelContext.executeTool(toolName, args)

Tool: launch_simulation
Description: Boots an AST Vector Simulation cartridge into the interactive apparatus from .ast or .astb bytecode.
Parameters:
  - preset (string, required): Canonical cartridge ID (e.g., 'velocity', 'electric-circuits', 'kinetic-gas', 'pythagoras', 'altar-anatomy')
  - speed (number, optional): Playback speed multiplier (default: 1.0)
  - autoPlay (boolean, optional): Begin immediate timeline playback (default: true)

Tool: list_ast_simulations
Description: Retrieves the catalog of all 67 certified vector curriculum cartridges with subjects, key stages, and physical invariant descriptors.
Parameters: none

Tool: evaluate_math_kernel
Description: Submits a continuous mathematical formula to the AST Math Compiler for affine single-cycle FMA decomposition and 6-float matrix compilation.
Parameters:
  - expr (string, required): Mathematical formula or transform string (e.g. 'translate(430 - 180 * t, 0)')
  - attr (string, optional): Target SVG attribute (e.g. 'transform', 'width', 'opacity')

Tool: translate_text
Description: Invokes the Universal Translator for real-time multilingual translation and speech boundary synchronization across English, Spanish, French, German, and Ecclesiastical Latin.
Parameters:
  - text (string, required): Source text to translate
  - targetLanguage (string, required): Target language code ('en', 'es', 'fr', 'la', 'de', 'it')

Tool: request_bsl_signing
Description: Broadcasts English text to the procedural 3D vector British Sign Language / Makaton interpreter avatar with Level 6 grammar synthesis.
Parameters:
  - text (string, required): English text string to transpile into Level 6 BSL grammar
  - signLanguage (string, optional): 'BSL' | 'MAKATON' (default: 'BSL')

Tool: catholic_catechism_search
Description: Queries the offline catechetical, liturgical, and scripture database for primary and secondary RE instruction.
Parameters:
  - query (string, required): Topic, sacrament, or liturgical calendar query
