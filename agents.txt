# -----------------------------------------------------------------------------
# 1. Architectural Superiority Manifesto & Tri-System Independence
# -----------------------------------------------------------------------------
# Unlike traditional monolithic web applications (Next.js, React, Nuxt, Docusaurus)
# that suffer from 2–5 MB JavaScript bundles, complex hydration mismatches, CPU-heavy
# virtual DOM diffing, and video streaming bills, this platform operates on three
# strictly standalone, zero-bloat systems unified by an asynchronous event bus:
#
# SYSTEM 1: THE PORTAL SITE SPA (Native Web Standards & Web Components)
# - Toolchain: Vite ^8.3.6 (Rolldown / esbuild ^0.28.1) & TypeScript ^5.6.3.
# - Framework: Zero React, Zero Virtual DOM, Zero Server-Side Hydration lag.
# - Bundle Budget: Initial critical SPA boot chunk strictly < 20 KB gzipped (~17.9 KB).
# - UI Architecture: Custom Web Components (<app-shell>, <native-bsl-interpreter>)
#   with in-memory micro-routing inside #ast-persistent-viewport via #page-outlet.
# - Stability: html { scrollbar-gutter: stable; } prevents Cumulative Layout Shift (CLS).
# - Offline Guarantee: 100% operational offline via ServiceWorker cache & IndexedDB.
# - Zero-Forced-Reflow: Geometric queries deferred to requestAnimationFrame; initial boot
#   skips window.scrollTo (already at 0,0); lazy chunks excluded from head modulepreload.
#
# SYSTEM 2: THE AST VECTOR PLAYER & FANTASY ENGINE (/static/player/, v2.6.0)
# - Autonomy: Completely decoupled runtime (< 35 KB core, ~107 KB all-in kernel gzipped)
#   with zero external dependencies. Pure schema-driven VM: ast-engine.js, site-gestures.js,
#   and declarative player-gestures.ast contain zero hardcoded scene IDs or cartridge selectors;
#   per-cartridge (:controls ...) switches gate platform features (:whiteboard, :xray, :audio,
#   :arrow-step, :num-jump, :scrub, :space-play, :quiz-keys, :param-hud), while extensible
#   registerAction() / registerGestureSkill() hooks and :if/:val-expr/:speak-expr/:tone-expr
#   evaluate declaratively via requestAnimationFrame. Runs standalone, in an iframe, or offline ZIP.
# - Fixed WASM Linear Memory: Strictly operates in a 7-page (448 KB) WASM linear memory
#   pool with zero dynamic heap allocations (no GC spikes) during 60 FPS physics loops.
# - 20–45x Lighter Than PhET: Boots in < 15 ms with < 8 MB RAM footprint (vs PhET's 2–5 MB
#   bundle, 1,200–2,500 ms boot time, and 45–90 MB RAM usage).
# - Tri-Mode Execution: Supports :Sim (continuous 60 FPS kinematics), :Slide (discrete
#   exploratory decks), and :Film (linear narrative choreography with time curves).
# - Negative-Space Compound Vectorization: Employs fill-rule="evenodd" compound paths
#   to carve mechanical apertures and voids into single DOM nodes with zero overdraw,
#   driven by single-cycle FMA 6-float affine matrix buffers (< 0.1 ms frame execution).
# - Smartboard Whiteboard Ink: Native in-stage quadratic Bézier vector annotation layer.
#
# SYSTEM 3: THE SOVEREIGN "IN-VISION" BSL / MAKATON VECTOR AVATAR
# - Zero-Video Architecture: Pure procedural SVG skeletal avatar running at 60 FPS
#   (< 15 KB uncompressed code, 0 KB external video feeds, £0 streaming bandwidth bills).
# - BSL Level 6 Linguistic Syntax Engine: 10-point 3D spatial register grid, directional
#   agreement verbs, polycomponential classifier predicates (CL:V, CL:B, CL:C, handling),
#   aspectual modulators (durative, intensive, habitual), and adverbial mouth morphemes.
# - Sovereign Uncoupling: Docks into the player/shell OR undocks into a separate desktop
#   window via the W3C Document Picture-in-Picture API (documentPictureInPicture).
#
# HARMONIOUS DECOUPLED DATA TIER (.ast & .astb)
# - Declarative Single Source of Truth: All 72 simulations, lessons, and lexicons are
#   authored as human-readable S-Expressions (.ast) and companion SVGs (.svg).
# - Pre-Compiled Binary Bytecode (.astb / .astbs): Compiled with ASTB magic header,
#   string table, and opcodes for sub-0.2 ms zero-copy binary deserialization.
# - Cryptographic Integrity: Validated against signed cartridge-checksums.json.
# - Inter-System Bus: The site, player, and BSL avatar communicate exclusively via
#   asynchronous postMessage events (SUBTITLE_UPDATE, SPEECH_BOUNDARY, TOGGLE_BSL)
#   and reactive local stores (bslGlobalStore, classroomBeacon WebRTC mesh).
#
# 3-TIER ON-DEVICE EDGE AI, GEMINI NANO AVAILABILITY & ECO MODE (0% CLOUD EGRESS)
# - Default Eco Mode (0 MB / 0 W GPU Draw): Runs pre-compiled deterministic Socratic
#   curriculum rules until explicit local opt-in (ai_model_download_consent in IndexedDB).
# - Passive Hardware Probe (src/engine/nanoAvailability.ts): Queries standard W3C
#   window.LanguageModel.availability() / self.LanguageModel.availability() during
#   requestIdleCallback (retired window.ai is never used), cleanly distinguishing:
#     * 'available'    — Gemini Nano weights installed locally and ready immediately
#     * 'downloadable' — Hardware & Chrome 128+ eligible; ready for local weight download
#     * 'downloading'  — Active local weight download with live 0–100% progress telemetry
#     * 'unavailable'  — API absent, hardware ineligible, or restricted by iframe policy
# - Strict Tier Separation: Tier-1 Chrome Gemini Nano availability is tracked independently
#   from Tier-2 WebGPU fallback (navigator.gpu + >= 4 GB deviceMemory guard, @mlc-ai/web-llm)
#   and Tier-3 Deterministic Socratic Rules (< 5 ms, 0 GPU allocations).
# - Transient User Activation Download: Clicking "Download & Activate Gemini Nano" in the
#   lazy-hydrated top-bar popover (#top-bar-nano-eco-btn -> NanoEcoPopover.ts), /settings#ai-engine,
#   or the Player's Ask Nano drawer invokes LanguageModel.create({ monitor }) synchronously
#   within the user gesture, streaming downloadprogress events before releasing the warm-up session.

# 3. On-Device Agent Capabilities & In-Browser Tools (Dual-Layer W3C WebMCP)
# -----------------------------------------------------------------------------
# Agents operating inside the client browser discover and invoke schema-validated
# tools registered via W3C WebMCP (navigator.modelContext / document.modelContext).
# Site-level tools (src/services/webMcpBridge.ts & src/engine/nanoSiteManager.ts)
# and Cartridge/Player runtime tools (src/engine/webmcpBridge.ts) coexist additively:

Tool: launch_simulation
Description: Boots an AST Vector Simulation cartridge into the interactive apparatus from .ast or .astb bytecode.
Parameters:
  - preset (string, required): Canonical cartridge ID (e.g., 'velocity', 'electric-circuits', 'kinetic-gas', 'pythagoras', 'altar-anatomy')

Tool: list_ast_simulations
Description: Retrieves the catalog of all 72 certified vector curriculum cartridges with subjects, key stages, and physical invariant descriptors.
Parameters:
  - subject (string, optional): Filter by subject area (e.g., 'Physics', 'Chemistry', 'Maths', 'RE')

Tool: navigate_portal
Description: Navigates the persistent SPA router in-memory to a curriculum route or interactive lab without full page reload.
Parameters:
  - path (string, required): Target portal route (e.g., '/player', '/learning-zone', '/catholic-life', '/phonics', '/revision')

Tool: catholic_catechism_search
Description: Queries the offline catechetical, liturgical, and scripture database for primary and secondary RE instruction.
Parameters:
  - query (string, required): Topic, sacrament, CST virtue, or liturgical calendar query

Tool: get_learner_status
Description: Reads private on-device mastery progress, sensory accessibility preferences, and Eco Mode / local state summary without cloud egress.
Parameters: none

Tool: site_get_manifest
Description: Returns the compact S-Expression site surface and route topology manifest for zero-bloat on-device agent navigation.
Parameters: none

Tool: site_manage_surface
Description: Actuates persistent shell accessibility controls (theme, high-contrast, font scaling, BSL/Makaton interpreter, data saver).
Parameters:
  - action (string, required): Surface control action identifier
  - value (string | boolean, optional): Target state value

Tool: site_dispatch_wasm_tuple
Description: Dispatches a validated declarative S-Expression command tuple to the active AST Vector Player stage.
Parameters:
  - tuple (string, required): S-Expression command tuple (e.g., '(:set-var "voltage" 9)')

# Note: When an interactive cartridge is mounted on /player, src/engine/webmcpBridge.ts

# with automatic AbortSignal teardown on cartridge unload.
